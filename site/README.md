# Preorder site (experiment E1)

One static file: `index.html`. No build step, no scripts, no tracking.

To go live:
1. Replace every `RESERVE_EMAIL` in index.html with the company mailbox address.
2. Push `work/` to the company GitHub repo; enable Pages on `main`, folder `/site`
   (or drop the `site/` folder on any static host).
3. Check the page on a phone. Click Reserve; the mail client must open with the subject filled.

Reservation emails are the data for E1 (brain/EXPERIMENTS.md). Pass line: >= 10 reservations from
strangers in 14 days.
